# 从参考到下一条视频：五步用法

## 1. 先说清这次要解决什么

写下一句话，例如：“观众需要看明白，哪个操作导致了哪个结果。”再列出已有稿件、真实录屏、可用工程和不能更改的部分。已有定稿保持原文，镜头围绕它安排。

只写稿、只找参考或只试一个动效时，完成对应任务即可；不自动扩展为整片制作。

## 2. 从已有库里找对应材料

优先查当前表达问题、产品页面或动作，不只查品牌名和“科技感”。检索可以返回几类不同材料：

| 材料 | 帮助判断什么 | 使用边界 |
|---|---|---|
| 外部参考片段 | 构图、动作、剪辑与声音怎样表达一件事 | 观察到的画面不等于拿到了作者工程，也不自动授予媒体转发权 |
| 真实产品原件 | 实际界面结构、操作与状态 | 只能支持检查范围内的产品事实 |
| 自有旧工程 | 已有实现怎样迁移到本次镜头 | 核对代码、依赖、资产与适用条件；旧项目采用不等于本次自动采用 |

有命中时回到原件，核对身份和对应片段。没有合适结果时记录缺口，可以寻找新材料或设计新的表达，不必强行套已有镜头。

## 3. 把参考拆成具体做法

填写参考卡，至少说明：片段在哪里、开始是什么状态、发生了什么、结束是什么状态、声音检查到哪里、哪些部分适合这次任务。

初筛时可以只记录粗略用途，并明确“待详细检查”。当一条宣传片被正式选为制作参考时，应完成所需的全片精拉：校正切点，核对镜头内动作、构图、衔接和声音；不能把初筛笔记写成已完成的精拉。

机器可准备切点、帧图、转写和音频信号等候选证据；实际动作、听感与叙事作用需要对应的观察依据。没有听过的音轨写“未听辨”，没有核对的连续动作写“未核实”。

## 4. 说明本次怎样使用

填写镜头采用记录。写清继承的做法、替换的内容、原片没有证明的部分，以及操作前、操作、响应、操作后的顺序。

需要真实产品画面时，把参考片的表达方法与产品原件的功能证据分别关联。业务数据、文件名和文档正文按当前任务调整，保持同一对象和前后结果一致。

已定镜头先做足够检查风险的短样。局部修改先固定实际候选版本与意见范围，保护未涉及的画面、时长和音轨。技术检查与正常速度观看、试听分别记录。

## 5. 把实际结果记回来

完成后记录：参考是否实际采用、用在哪里、改了什么、为什么放弃、检查了什么，以及用户明确认可了哪个范围。未审阅的候选保持未审阅。

资产库保留材料身份和通用方法；项目采用记录保留本次选择与反馈。样片和候选留项目工作目录，只有用户明确指定存档的成片才按既有归档规则入库。

下一次遇到相似需求，先查这些结果。衡量是否有帮助，可以看“找到后有没有用上、没用上的原因、是否还需从头寻找”；尚未测量时不填写节省时间或提效百分比。

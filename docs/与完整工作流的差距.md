# 当前发行代码与完整工作流的差距

对照日期2026-10-29，当前v0.7.2。完整工作流是本工作区的工具、规则、服务和积累共同组成的环境。包内只迁移通用代码和方法，不带原件、账号、批次授权或私人分析；不按文件数量估算完成比例。

| 产品片段卡 | 产品/反馈/聊天角色隔离、原件复制核验、结构/动作片段、仅发布已复核片段、按页面动作查找 | 工具验证字段，不证明实际观察；新手与跨系统实机验收未完成 |

# 安装随包打标插件

本包包含`plugins/codex-video-review/`的源码、插件声明、MCP声明、页面、已构建前端、锁定依赖清单、技能与验证脚本；不包含Node、npm依赖目录、Codex客户端或账号。把文件放进zip不等于已在接收者AI里启用插件。

## 安装依赖

在解压后的包根目录运行：

```sh
python3 video_review.py doctor
python3 video_review.py setup
python3 video_review.py config
```

setup会执行锁文件驱动的`npm ci --ignore-scripts`，需要可访问npm或已有完整公开依赖缓存。离线已有缓存时可用`setup --offline`。安装依赖不改宿主全局设置。doctor分别报告运行时、依赖和浏览器bundle，不把“文件存在”当作已连接AI。

## 接到AI里

将config输出的`mcpServers.codex_video_review`连接配置添加到宿主支持的本地MCP配置中。输出使用当前解压目录的真实绝对路径，不能照抄别人电脑的配置；安装后目录移动需要重新生成配置。采用插件市场方式安装时也应指向本包插件目录；本包不假设接收者配置了作者的personal市场。

Codex CLI支持`codex mcp add <名称> -- <命令> <参数...>`。例如在实际路径替换完成后，把Node作为命令，把本包插件内`mcp/server.mjs`绝对路径作为参数。命令会修改该用户的MCP配置，本包不会替用户执行。已经安装同名插件时使用已有入口，不重复注册。按宿主要求重新加载后，确认出现open_video_review与get_video_review_notes等工具。

把`plugins/codex-video-review/skills/video-review/`整个目录安装到同一宿主的技能目录，或使用宿主原生插件加载方式加载其skills。video-making-kit已有打标路由，不需复制全局AGENTS.md。

## 打开与读取

让Agent调用`open_video_review`，传实际视频和项目绝对路径；使用返回的reviewUrl打开打标页，核实播放与圈选。Codex可用open_in_codex在右侧显示。不能用/video地址代替/review。

尚未连接MCP时可临时验证页面：

```sh
python3 video_review.py open --project /实际项目目录 --file /实际项目目录/out/candidate.mp4
```

保持该命令运行，在浏览器打开打印的URL；Ctrl+C结束本次服务。CLI临时打开不保证绑定当前对话。标注保存后回对话说明已标注，由Agent读取项目内该视频SHA-256的记录。正式连接MCP后使用get_video_review_notes，核对哈希、时刻、坐标与参考图，再局部修改，保护未标镜头和音轨。

发送按钮依赖宿主。若不可用，先保存再回当前对话通知；不能说“已自动发送”。该快照的原发送路径固定gpt-6-sol；其他模型或宿主兼容性未承诺。未批准的反馈不能变成批准成片。

## 验证范围

本轮在macOS从修订zip的独立解包目录安装依赖，验证运行与标注读写；跨系统、普通新手独立安装和宿主插件注册流程未实机验收。接口测试用临时合成数据和假消息执行器，不等于真实Codex自动修改已通过。

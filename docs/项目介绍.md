# 宣传片工作流工具包

这是一套交给 AI 使用的宣传片制作工具：从题目或定稿出发，完成分镜、素材准备、旁白配乐、剪辑导出、检查和局部修改，并保留能继续编辑的工程。

包里包含自建素材库、参考视频拆解、363 条通用动效配方／样式、配音与 Google 音乐生成接入，以及视频打标和版本回退工具。还整理了实际制作中积累的 24 项避雷规则，帮助检查画面与旁白不符、假界面、鼠标漂移、反复缩放、音乐接头和修改范围失控等问题。

你可以使用自己的录屏、图片、音乐和参考素材，建立自己的资料库。包里不包含作者的私人素材、生产数据库、账号、API Key 或模型额度；需要生成内容时，使用自己的服务账号。

当前是测试预览版，适合愿意和 AI 一起做片、审片和调整的创作者。它已经通过 49 项自动测试，并完成过全新素材的有声短片制作测试；这些不等于所有题目都能自动做好，也不代表已经完成新手独立安装和跨系统验证。

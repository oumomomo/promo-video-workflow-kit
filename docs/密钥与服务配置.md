# 密钥与服务配置

先读[首次使用](首次使用.md)。下面按本仓库实际实现说明，不表示服务注册后一定有额度、模型权限或地域可用性。官方入口于2026-10-29核对；本轮安装自检没有发送付费请求。

## 哪些是必需的

| 功能 | 当前代码读取的配置 | 是否所有人都需要 |
|---|---|---|
| 基础制作、导出、素材库、动效检索、本地分析和打标 | 无云API Key | 都不需要包内服务密钥；本地运行时/模块依赖另装 |
| 中文旁白（豆包V3语音合成） | `DOUBAO_TTS_API_KEY`，或macOS钥匙串 | 需要生成中文配音时才配置 |
| Google音乐（默认API Key路径） | `GEMINI_API_KEY`，兼容`GOOGLE_API_KEY`，或macOS钥匙串 | 需要生成音乐时才配置；用自己的音乐无需配置 |
| 英文旁白（Cloud Text-to-Speech） | `GOOGLE_CLOUD_PROJECT`、Google Cloud CLI和ADC登录 | 需要这条英文配音路径时才配置 |
| 云端视频/声音分析（Vertex） | 同上；可选`VIDEO_ANALYSIS_MODEL` | 需要云语义分析时才配置 |
| Google音乐（可选Vertex路径） | 显式`--auth adc --project-id 自己的项目` | 与API Key路径二选一，不必同时配置 |
| AI宿主、图像/视频生成 | 宿主或对应工具自己的配置 | 不由此包统一提供或读取，没有“通用图片Key” |

`GOOGLE_CLOUD_PROJECT`是项目标识，不是密码。API Key是密钥；ADC是通过Google登录取得并由gcloud管理的凭据。本包目前的英文配音/云分析只实现ADC路线，不能把AI Studio的音乐Key填进去就当作完成了这两项服务配置。

AI宿主可能用订阅登录，也可能用其模型服务的Key。此包没有额外强制OpenAI Key或GitHub Token；自己在GitHub下载使用和向上游提交代码是不同事情。不要把作者的任何凭据复制给使用者。

## 1. Google生成音乐：API Key路径

到[Google AI Studio的API Key页面](https://aistudio.google.com/apikey)为自己的项目创建并管理Key，按官方要求开通相应模型和计费/额度。[官方Key说明](https://ai.google.dev/gemini-api/docs/api-key)。

macOS在仓库根目录运行：

```sh
python3 video_tools.py music configure-key
```

在终端提示时输入自己的Key，不回显，写入当前用户钥匙串的`video-workflow-gemini-api-key`。代码、项目和请求回执不保存Key。Windows/Linux此交互命令不支持钥匙串，请在系统或宿主的受保护环境设置`GEMINI_API_KEY`，然后从能继承该变量的终端运行。

只选一个变量。当前本包的自有REST实现先读`GEMINI_API_KEY`、再读`GOOGLE_API_KEY`，两者同时存在可能使你误用旧Key；这不是声称Google SDK也采用相同优先级。

先建立实际音乐提示文件，再运行：

```sh
python3 video_tools.py music generate --prompt-file music-prompt.txt --output-dir music --dry-run
```

dry-run不会读取/验证Key，不发请求。确认本次服务调用在已有授权范围内后，再去掉`--dry-run`生成。默认模型在代码中为`lyria-3-clip-preview`，实际可用性以自己的账号和官方为准。当前发行的API Key路径只有模拟接口测试，不能因为ADC生成成功就称Key路径已实调。

## 2. 中文旁白：豆包语音Key

从火山引擎的豆包语音控制台获取语音服务API Key，开通所需语音合成资源与音色权限。当前代码使用新版V3的`X-Api-Key`，默认资源为`seed-tts-2.0`。它不读取火山云通用AccessKey/SecretKey，也不是让你填写聊天模型的Key。[官方V3鉴权说明](https://docs.volcengine.com/docs/DoubaoVoice/WebSocketBidirectionalStreaming-V3?lang=zh)。

在同一个Python环境安装扩展requirements后，macOS运行：

```sh
python3 video_tools.py voice configure-doubao
```

提示时输入自己的语音Key，保存到`video-workflow-doubao-tts-api-key`钥匙串项。Windows/Linux使用受保护的`DOUBAO_TTS_API_KEY`环境变量。当前V3实现不要求另填旧版APP ID；保留的`--app-id`参数不表示本包实现了旧版App ID+Token鉴权。

先对实际脚本准备请求：

```sh
python3 video_tools.py voice synthesize --text-file film/workflow/script.locked.txt --output-dir film/voice --dry-run
```

dry-run不合成、不验证Key。中文和含中文混合稿当前路由到豆包，纯拉丁文字路由到英文Google；这不是完整多语种自动识别。语音资源或音色确需更换时，可用`DOUBAO_TTS_RESOURCE_ID`、`DOUBAO_TTS_VOICE_TYPE`，无需为了首次使用先填写这些可选参数。

## 3. 英文配音/云分析：Google Cloud ADC

先准备自己的Google Cloud项目，按对应产品文档开通服务、计费和所需权限：英文旁白调用Cloud Text-to-Speech；视频/声音分析调用Vertex。一个ADC登录可供多条路径使用，但拥有一种服务的权限不证明拥有另一种服务或模型的权限。

安装Google Cloud CLI后，在自己的机器交互登录：

```sh
gcloud auth application-default login
gcloud auth application-default set-quota-project your-project-id
```

将`your-project-id`换为自己的实际项目ID。另在当前运行环境设置`GOOGLE_CLOUD_PROJECT`，或者为支持该参数的声音/音乐命令显式传`--project-id`。不要复制作者项目，不要把访问令牌填进项目文件，也不要将ADC凭据文件上传GitHub。本包通过gcloud取得短期令牌，不要求初学者下载并分发长期服务账号私钥。

普通`gcloud auth login`与ADC配置不同；当前代码使用`application-default print-access-token`，前者登录成功不能证明本包ADC配置完成。[Google ADC说明](https://docs.cloud.google.com/docs/authentication/provide-credentials-adc) · [Cloud Gemini-TTS说明](https://docs.cloud.google.com/text-to-speech/docs/gemini-tts)。

云分析还需要覆盖本次原件哈希、服务端点和模式的真实上传授权记录。按[分析命令](../skills/video-production-tools/references/operations.md)操作，不伪造授权。只执行`--cloud none`时不需要登录Google，也不上传原片；未使用`--submit`时不向主素材库登记分析。

音乐选用Vertex时必须显式指定，未配置不会降级借用其他账号：

```sh
python3 video_tools.py music generate --auth adc --project-id your-project-id --prompt-file music-prompt.txt --output-dir music --dry-run
```

## 4. 怎样判断配置到哪一步

1. `python3 video_setup.py doctor --feature music`等命令检查运行依赖。默认不读取钥匙串/ADC，不验证登录或权限；环境变量只报告是否存在，不报告值。
2. dry-run准备请求，不验证密钥或云服务；调用前先看具体发送内容与本次授权。
3. 真正调用的响应才说明这一次请求是否被服务接受；保留请求身份、费用和结果，不自动重发不确定的付费请求。
4. 音频完整、解码成功与实际听感分别检查。Key配置成功不意味着声音好听或已经批准发布。

不需要把Key发给聊天助手。密钥可在自己的终端提示或受保护的环境中填写；不要提交`.env`、截图、日志或凭据文件。遇到失败，提供已去除密钥的错误类型、状态码及回执状态即可。

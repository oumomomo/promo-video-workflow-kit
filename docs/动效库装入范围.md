## 别人装上后能做什么

让AI按本镜头的目的找动效，读完整配方和准确源码，选择复用、混合或原创。命令可以导出源码依赖与许可证，为无媒体缺口的Remotion条目创建单镜工程，记录实际选择。渲染需要使用者安装Node/npm、React／Remotion与浏览器，代码里依赖的产品内容用本次素材替换。

网页悬停／滚动效果需要改成视频帧控制；包中不会将它们假称为现成的视频镜头。原Demo里的占位界面与数字用于展示运动，不是产品事实，也不是审美默认模板。

## 与现有流程如何连接

**脚本 → 事件分镜 → 搜索动效配方 → 查看准确源码 → 替换为本片内容并实现 → 输出单镜视频 → 加入制作项目剪辑 → 检查与审片。**

原统一库继续作为本机生产真源；分发目录只读，不另建一套可编辑生产主库。测试与构建不修改统一库。

已经跑通的命令和结构测试不证明每条源码都已在目标机器正常渲染。完整渲染、正常速度检查、声音与真人审美仍按当前制作项目执行。

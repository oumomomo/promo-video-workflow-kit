# 安装与制作

这是交给AI使用的技能包，不是双击就自动生成视频的桌面软件。

1. 解压源码包。安装 Python 3.10+、FFmpeg／ffprobe；参考整理还需要 Node 18+。制作执行器不要求Node。
2. 将 `skills/video-making-kit` **整个文件夹**放入所用AI工具支持的技能目录。例如Codex项目使用 `.agents/skills/video-making-kit/`。只复制SKILL.md会丢失执行脚本。本次制作需要动效库时，同时安装整个 `skills/video-motion-kit`；参考整理需要时另安装 `video-reference-kit`。
需要自建素材库时，将video-asset-library与video-reference-kit整个目录同级安装；参考[建库方法](建立自己的素材库.md)。只建库与登记不要求Node/FFmpeg，做视频分析时才需要这些运行时。

3. 告诉AI：使用 video-making-kit，为某个新题目制作一条视频。提供已有图片／录屏，或者让AI调用当前可用的生成工具。生成工具、模型额度和素材版权不包含在包内。
4. AI完成写稿、分镜、准备素材，再调用包内脚本导出视频。它应交付MP4和工程，并说明实际检查范围。
5. 本包已带打标插件，按[打标插件安装](打标插件安装.md)安装依赖并接入宿主；审看后指出问题或在实际可用的打标插件里标注，AI按范围修改。没有打标插件不影响导出视频，但不会自动获得标注功能。

可以直接发给AI：

> 使用 video-making-kit，给一个虚构品牌制作15秒新品短片。你来写稿和选视觉方向。不要借用以前的素材或旧工程；需要素材时使用本次新生成或我提供的内容。交付实际视频、分镜、可恢复工程和检查记录；不要把渲染成功当作我已认可效果。

只想手动检查环境：在解压目录运行 `python3 video_make.py doctor`。这条命令只检查运行条件，不会产生视频。

当前版本是GitHub测试预览版；自有部分采用MIT，第三方保留原许可。不同系统与真实新手独立使用尚未完成实机验证。已有完整制作通路也不等于每个题目都有好效果；需通过实际作品判断。

生产扩展请将video-production-tools与同包基础技能同级安装，按其requirements.txt安装Python依赖。配置自己的服务前可使用本地分析、片段卡和账本；云端视频/声音分析与TTS需要自己的账号和授权，安装包不提供额度。完整命令见video-production-tools/references/operations.md。

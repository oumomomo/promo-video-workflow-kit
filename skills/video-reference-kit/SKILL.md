# 视频参考整理与复用

脚本入口为本技能中的 `scripts/video_ref.py`。先运行 `doctor` 检查 Python、Node、FFmpeg 与 ffprobe，再按任务调用命令。具体用法见[命令与笔记格式](references/commands.md)。

有 `OMM_ASSET_CONFIG` 或默认统一库配置时，使用原入口；配置异常停止，不另建主库。无统一库的外部使用者才显式初始化自己的便携库。不要把技能安装目录当素材存储位置。

## 取用顺序

1. 制作前按当前表达问题检索。准备新原件时，程序按 SHA-256 查重；命中本工具的有效证据则复用并保留笔记。其他来源的已有分析先读覆盖范围，不把未读摘要当已复核。
2. `prepare` 只处理用户指定的本地视频，输出切镜候选、运动测量、首尾关键帧和音轨存在性。原件副本与各项证据校验哈希，未核对的画面和声音保持待复核。默认限制180秒和80个切镜候选，超限后按当前范围决定是否明确调整。
3. 正式采用前实际看对应原片、连续动作与必要过程帧；复杂动作不能只靠首尾帧推断。宣传片的详细拉片范围仍按当前项目要求完成，本工具的机器底稿不代表精拉完成。
4. 用 `notes template` 创建绑定原片哈希的笔记。根据实际观察填摘要、检查方式及范围、片段、继承、改变和排除项；声音未听过就保留未听辨。再用 `notes submit` 保存版本。用户定稿不因整理参考被改写。
5. `search` 可检索已保存正文。采用前 `get` 回读身份；`bind` 引用已记录片段并绑定分析版本，写入当前项目与同一主库采用记录。计划采用不等于已制作或用户批准。

## 边界

表达参考不自动成为产品UI真源。真实产品的结构与功能依据仍须按项目要求核对，不能把不同材料拼成未经证明的操作链。

`bind --use reference` 表示借鉴做法；`--use media` 表示计划直接采用原画面，要求使用者提供权利声明与依据。程序只记录声明，不能判定许可是否真实有效。

候选视频和反馈仍留项目工作文件，不自动纳入素材库。本工具只登记外部参考、观察笔记和项目引用，不授予成片归档或发布权限。导出保留原记录正文和定位信息，不能默认当成已脱敏的公开包。

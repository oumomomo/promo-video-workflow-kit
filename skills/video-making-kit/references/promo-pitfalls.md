# 宣传片避雷：从承诺、画面到交付

新宣传片第一次写分镜前、收到负面反馈后，以及最终交付前读取本文件。按当前任务选适用条目，记录不适用的理由；不要为凑齐清单给视频增加内容。

## 适用范围和记录方法

本清单提炼自两轮实际产品宣传片制作复盘（2026-09-24、2026-10-09）、维护中的制作经验与高频踩雷点，以及2026-10-29安装包样片暴露的问题。它不是完整历史聊天，也不是已证明每项都被工具自动执行的保证。没有携带旧素材、私人反馈原件、产品分析语料、账号或项目路径。

保留通用方法：同一对象的操作链、原片结构复刻、鼠标与镜头定位、连续音乐、按范围修改、实际文件验收。原系列的字体、英文文案、字卡秒数、蓝白配色、4K/60fps、具体文件类型名称和产品功能不是新用户默认值。按当前品牌、观众、平台、原片和最新要求重新决定。

将本次选择和发现写入项目的 `workflow/promo-review.md`，可复制包根目录的 `templates/promo-review.md`。保持旧版记录或明确标失效，不反复覆盖历史结论。每个问题至少有：规则ID、镜头/区间、可观察问题、依据、处理、复查范围、状态。未知写待核实，不能把“已读规则”勾成“效果通过”。

## 2. 真实产品与操作演示

| ID | 常见失败 | 制作与检查方法 |
|---|---|---|
| P05 | 只看标题、摘要或资产ID，就画一套“差不多”的界面 | 先取回并查看真实原件的对应页面/时间。逐镜保存原片帧与候选帧，继承布局、控件、字段、图标和状态；按当前任务替换示例数据。登记/检索命中不等于已看过或已学会。 |
| P06 | 将不同页面拼成功能链；修改前结果已更新 | 核对同一对象的“操作前→操作→响应→操作后”。先改变源，再展示结果；人工确认在前，合并结果在后。没有原片证据的因果不得靠相似页面补齐。 |
| P07 | 鼠标漂移、双指针、重复点击、无关绕行 | 鼠标与控件共享同一场景坐标及镜头变换。核对实际点击帧和随后响应；只保留必要点击。移动距离变化时重新安排时长，不套一条万能轨迹。 |
| P08 | 为强调反复缩放；放大遮掉工具栏或比较区域 | 先建立位置，再聚焦操作，留出看清结果的时间。排查相机和对象的叠加运动、回摆、重影。完整对照是证据时不能裁掉半边；画幅按需要同时看见的内容选，不机械平移弥补错误画幅。 |

## 3. AI味、构图与文字

| ID | 常见失败 | 制作与检查方法 |
|---|---|---|
| P09 | 所有题目都用假窗口、玻璃卡片、发光线、同一弹性入场 | 从真实产品、具体对象、人的行为、品牌资产或明确隐喻确定材料和运动。更换圆角、颜色或字体不等于解决同一个泛用模板问题。AI能指出具体失败，不能自签“没有AI味”。 |
| P10 | 误把颜色、大留白、原生小字或居中一律当AI味 | 判断这些选择的来源和职责，不建立表面黑名单。真实品牌色可以保留；阅读界面可以停留；统一的是本片逻辑，不是所有宣传片长一样。 |
| P11 | 多个高亮抢主体、比例失真、装饰线填空 | 稳定构图明确一个首要阅读中心；动态焦点可以按顺序转移。检查透视、比例、遮挡和裁切。线条须回答连接谁、表示什么、去掉损失什么；说不清就删，真实界面或测量线不机械删除。 |
| P12 | 口播、标题、小标签重复解释；满屏字来不及读 | 默认不随手增加说明。保留获准稿件原话、真实界面文字和理解所需的证据；记录必要性。按实际字号/字重/字距/换行检查最终编码画面，不能只看字体family或单张设计稿。 |

## 4. 节奏和接头

| ID | 常见失败 | 制作与检查方法 |
|---|---|---|
| P13 | 空停留过久、动作太快、到达后没有阅读时间 | 时长服务信息量与事件。区分移动、点击、响应、阅读；移动可快，关键点击及结果须看得见。不得把某片的0.5秒、3.5秒或固定缓动套给全部题目。 |
| P14 | 闪帧、旧画面残留、双层重影、持续闪烁 | 查最终编码的切点前后及静止区连续帧，并正常速度观看。单张截图、60fps、均匀时间戳或解码成功都不能证明不闪、流畅。先查重复实例和叠加变换，不能只追加缓动。 |
| P15 | 字卡打断同一操作；输出与打开另起无关页面 | 字卡放在语义段落边界，保持对象、位置和操作承接。修改或删镜后重新核对相邻接头，避免空白、重复口播、漏帧与提前显示。 |

## 5. 旁白、音乐和音效

| ID | 常见失败 | 制作与检查方法 |
|---|---|---|
| P16 | 换了配音却沿用旧字幕/动作时间；为卡点拖词 | 分别锁定原文、音频文件哈希、变速/剪切处理和时序。稿件哈希相同不证明口播一样。没有ASR或实听证据时，不把按标点猜测称为逐词时码；语义正确优先于鼓点。 |
| P17 | 音乐补长就从头重复、尾音切断、只有鼓点没有乐句 | 先实际听辨旋律、节奏、转折和收尾，再安排画面。优先保持乐句连续；改长度需复听全部接头。BPM、响度、淡化或生成成功不能证明音乐顺畅。 |
| P18 | 全程“咻咻咻”；音效全对齐镜头起点 | 按点击、输入、移动、到达、完成选择声音，滚动和阅读可以安静。登记实际起音、可见动作帧、增益和试听结论。文件起点对齐不等于听感对齐；不无故重置已认可音色。 |
| P19 | BGM盖口播；无削波就说好听；缓存失效自动重复付费 | 分开检查旁白/音乐/音效原件、关键独奏及最终混音。信号测量和听辨分别记录；没听过就保留待听。缓存按请求及文件身份核对，失败或不确定的付费请求不盲目重试。 |

## 六个执行时点

1. **开工**：确认观众、唯一目标、品牌、平台、真实/虚构角色、功能依据、基线与禁用内容；选适用规则。
2. **分镜**：核对主张、原片、对象状态、动作和结果，检查是否只剩字卡或名词配图。
3. **风险短样**：先验证最易出错的真实UI、手部/物理动作、鼠标、联动或接头；已有制作授权时继续，不为清单另加反复审批。
4. **整片**：查看最终编码画面，核对连续性、文字、节奏与声音；已看到的具体错误先修，不以列为已知问题代替可做的修复。
5. **局改**：读取同一文件哈希的反馈，保护未标部分，按问题复查及记录未关闭项。
6. **交付**：实际视频、可恢复工程、检查范围与可用审片入口同时给出；待真人判断的项目保留待评审。

本清单属于Agent执行指引。脚本只自动核对其实际实现的字段、哈希、时间和编解码项，不自动理解全部语义，不认证听感、审美或批准。

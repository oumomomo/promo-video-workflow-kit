# 随包视频打标插件

来源为个人插件codex-video-review 0.1.15+codex.20260928的本地快照；不是公共市场安装完成的声明。源码来源及发行改动见SOURCE.json。维护者已确认插件应用代码可按仓库根目录MIT许可公开；依赖许可另见DEPENDENCY-NOTICES.md。

可播放本地视频，画笔、线、箭头、圈选，保存文字与参考图；意见绑定视频SHA-256，支持读取、修改和删除。原视频不复制、不改写。标注保存在所属项目的`.codex-video-review/`。这些记录和附件不随安装包分发。

从源码包根目录按`docs/打标插件安装.md`安装依赖并连接MCP。需要Node.js20+和npm；不含node_modules或Node二进制，已附可运行浏览器bundle。`npm ci --ignore-scripts`根据锁文件安装依赖，不要求本机重新构建UI。开发修改src/widget.js时才需要`npm run build`同步dist/widget.js。

创建打标页后先保存标注。发送按钮取决于宿主桥接、会话身份与Codex支持；不支持时只能保存，回到当前对话通知Agent读取。当前源版发送路径固定使用gpt-6-sol，未确认支持时禁用或报错；不保证任意AI宿主都能自动发送，不允许冒充发送成功。测试里的消息发送通过本地假执行器验证，不向真实会话发消息。

`node scripts/probe.mjs`从本插件目录执行，用临时合成数据验证MCP、页面、Range视频流、哈希绑定、标注读写、附件、去重与错误处理。FFmpeg用于其中的视频测试；mcp/render_review_frame.py为可选抽帧标记辅助，额外需要Python/Pillow，浏览器打标本身不需要它。

服务仅监听127.0.0.1随机端口。页面链接只在该MCP进程存活时有效。视频必须位于指定项目目录；用真实路径校验，不能用符号链接越界。相同视频重开会读取该哈希的已存意见。

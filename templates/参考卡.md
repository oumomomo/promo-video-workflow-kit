# 参考卡

空白填写模板。已有资产系统时使用现有资产 ID 与正文版本；本表可以作为项目导出，不另建资产总表。

| 项目 | 填写 |
|---|---|
| 现有资产 ID／材料名称 | 待填 |
| 材料角色 | 外部表达参考／真实产品原件／自有实现／待判 |
| 原始来源与版本 | 待填 |
| 原件定位与内容哈希 | 待填；公开分享时不暴露个人路径或私有访问令牌 |
| 使用权限及依据 | 待核实；区分制作使用与原件再分发 |
| 检查范围 | 实际看过的时间段或页面；是否连续播放；声音是否听辨 |
| 解决什么表达问题 | 待填 |
| 片段起点与终点 | 采用实际时间证据；未知则待核实 |
| 开始状态 → 动作 → 结果 | 待填 |
| 构图、运镜与衔接 | 待填，并说明观察依据 |
| 声音作用 | 待填；未听辨则保留未知 |
| 值得借鉴的做法 | 待填 |
| 不适用或不能推断的部分 | 待填 |
| 检查人／执行方式／日期 | 待填；模型候选与人工观察分别注明 |
| 当前状态 | 初筛／待核实／已检查；注明状态对应的具体范围 |

已登记、文件存在、模型完成分析均不自动等于可以采用或已获用户批准。
